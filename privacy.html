Privacy Policy

This policy details how user data, API credentials, and assessment records are handled.

1. Architecture and Data Handling

This application operates as a client-side web application. All quiz generation configurations, user interactions, and grading computations are processed within your local web browser session.

2. Gemini API Credentials

This platform follows a strict Bring Your Own Key (BYOK) architecture:

  • Local Storage Only: If you choose to input a Google Gemini API key, it is stored solely within your web browser's local storage (window.localStorage).
  • No Intermediate Server Storage: Your API key is never transmitted to, logged on, or stored on any intermediary server operated by this application.
  • Direct Transmission: When you generate a quiz using AI, network requests are transmitted directly from your client browser to Google's official Generative Language API endpoint (generativelanguage.googleapis.com).
  • Revocation and Deletion: You can permanently remove your saved API key from local storage at any time by clicking the "Clear" button in the API settings module.

3. Third-Party Services

When using AI quiz generation, your requests are processed by Google in accordance with Google's API Terms of Service and Privacy Policy. We do not control Google's processing of data sent to their endpoints.

4. Cookies and Tracking

This application does not use tracking cookies, analytics trackers, or third-party marketing scripts. The only stored items in your browser are your voluntarily provided API key and current test state.

5. Changes to This Policy

Any updates to this policy will be posted on this page with an updated effective date.

6. Contact

For questions regarding this privacy policy, open an issue in the project source repository.
